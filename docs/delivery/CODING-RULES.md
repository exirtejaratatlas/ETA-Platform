# ETA Platform Coding Rules

## SOURCE OF TRUTH

ETA-Blueprint

## DEVELOPMENT REPOSITORY

ETA-Platform

---

## Allowed

The development team may:

- Implement approved Architecture
- Implement approved Domain Model
- Implement approved Entity Model
- Implement approved UI Map
- Implement approved API Contracts

---

## Forbidden without Change Request

The development team must not introduce:

- Architecture changes
- Database redesign
- AI automation
- ERP integration
- Production deployment decisions

---

## Development Principle

ETA-Blueprint remains the authoritative source for:

- Business decisions
- Architecture decisions
- Domain definitions
- Approved requirements

ETA-Platform is the implementation repository.

Obsidian remains the project memory layer and graph knowledge system.

Any major change must first be documented in ETA-Blueprint through the approved Change Request process.
